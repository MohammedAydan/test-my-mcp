# Voiceover

Final and scratch voiceover takes.

- WAV 48 kHz mono is safest; the encoder produces the AAC track.
- Naming: `vo-{lang}-take{N}.wav` (e.g. `vo-ar-take2.wav`).
- Keep scratch takes here, promote only the approved take to `assets/`.
- Loudness target: −16 LUFS integrated, −3 dBTP peak.
