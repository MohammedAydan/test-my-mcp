# Custom SFX

Only for sounds outside the engine's built-in bank.

The engine bank is always available with no upload:
`whoosh · pop · click · subImpact · shimmer · riser`

Custom sounds are referenced the same way — declare them in `assets[]` and cue
them by absolute time in `audio.cues[]`. This folder exists for licensed or
bespoke hits (a logo clang, a UI tick) that the bank cannot cover.
