# Scene templates

Reference SceneSpecs shipped with the project kit. They are valid out of the box
and are regenerated from `@motionforge/scene-spec` (never hand-edited):

- `minimal-valid-scene.json` — smallest scene that passes validation
- `showcase-sketch.json` — every asset-free feature in one scene

Copy one to `scenes/scene-02.json` and edit from there, or just author
`scenes/scene-01.json` directly with the `get_motion_capabilities` tool.
