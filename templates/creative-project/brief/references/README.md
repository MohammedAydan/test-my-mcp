# References

Moodboards, competitor stills and client-supplied visual references.

- Images: `.png` / `.jpg` / `.webp`, ≤ 2000 px on the long edge.
- Keep the file list short and name files after the idea they express
  (`mood-dark-editorial-01.jpg`), never `IMG_4821.jpg`.
- Link them from the **References** section of `../BRIEF.md`.

Nothing here reaches the engine — this folder is context for humans and agents.
