# Photoshop masters

Layered `.psd` composites for every frame or layout that needs hand-tuning.

- These are **human** masters. The engine never reads them.
- Export any element the video needs into `../../assets/images/` as PNG/WebP.
- Name exports `bg-{scene}-{n}-4k.png`, `icon-{name}.png`, …
- Keep the canvas at the brief's aspect (1920×1080 or 1080×1920).
