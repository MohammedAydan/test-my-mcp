# Storyboard

Frame-by-frame plan for the whole piece, one image (or PDF page) per beat.

- One row per beat: timestamp, visual, copy, SFX cue.
- Beats follow the rhythm in `../../brand/guidelines.md` (one idea per 2–4 s).
- The storyboard is the reference for `inspect_scene_keyframes` timestamps —
  inspect at least every beat boundary.
- Export as `beat-01.png`, `beat-02.png`, … or one `storyboard.pdf`.
