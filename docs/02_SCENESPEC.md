# SceneSpec v1 — Reference

The declarative scene contract. All packages (and the LLM) speak this language.
Schema source of truth: `packages/scene-spec/src/**` (Zod, strict — unknown keys are
validation errors). All times are **milliseconds**, all positions are **percent of
canvas**, all font sizes/lengths are **design px** (authored against the canvas scale).

> **v3.0 (2026-10-20):** Track lane assignment (`trackIndex`) is now part of
> `layerBaseSchema`, together with the whole universal spatial set
> (`position`, `scale`, `rotation`, `opacity`, `visible`, `locked`,
> `blendMode`). See "The universal spatial / NLE set" below.


> **Machine-readable twin of this document.** Everything below is also emitted
> programmatically so an agent never has to guess or read source: call
> `get_motion_capabilities` (MCP) / `GET /api/capabilities` (HTTP), or read the MCP
> resource `motionforge://scenespec/v1`. Both carry `layerFieldGuide` (required/optional
> keys + a schema-valid example per layer type), `nestedShapeNotes`, `minimalValidScene`
> (guaranteed valid — copy it), `fullShowcaseSketch`, `units` and every `registries`
> list. Generated by `packages/scene-spec/src/field-guide.ts`, which is typed as
> `SceneSpecInput` and covered by `tests/field-guide.spec.ts`, so the guidance cannot
> drift from the schemas.
>
> **Start from `minimalValidScene`,** not from a blank object.

## Two validation layers (and where each rule lives)

| Layer | Schema | Enforces | Error surface |
| --- | --- | --- | --- |
| Structural | `sceneShapeSchema` (exported; strict object, no cross-field rules) | field presence, types, enums, nested shapes, unknown keys | MCP host pre-validation **and** engine 400 `issues[]` |
| Full | `sceneSpecSchema` (= `sceneShapeSchema.superRefine(...)`) | plus cross-field rules below | engine 400 `issues[]`, forwarded verbatim by the MCP adapter |

Both accept identical fields. Hosts that need to *advertise* the structure (MCP tool
input schemas must be a `ZodObject`) use `sceneShapeSchema`; `sceneSpecSchema` stays
the single validator. **MCP must never swallow `issues[]`** — the agent needs the exact
field paths to self-correct (see `docs/01_ARCHITECTURE.md` §6).

## Top level

```jsonc
{
  "schemaVersion": 1,
  "name": "Brand Intro",
  "canvas": { "shape": "16:9", "scale": 1080 },   // → 1920×1080
  "durationMs": 12000,
  "assets": [ /* see Assets */ ],
  "fonts":  [ /* see Fonts */ ],
  "layers": [ /* see Layers */ ],
  "camera": { /* see Camera */ },
  "transitions": [ /* see Transitions */ ],
  "audio": { "music": {…}, "cues": [ {…} ] }
}
```

### Canvas
`shape` × `scale` → pixel size (validated pairs):

| shape | 720 | 1080 | 1440 | 2160 |
|---|---|---|---|---|
| `16:9` | 1280×720 | **1920×1080** | 2560×1440 | 3840×2160 |
| `9:16` | 720×1280 | 1080×1920 | 1440×2560 | 2160×3840 |
| `1:1` | — | 1080×1080 | — | 2160×2160 |
| `4:5` | — | 1080×1350 | — | 2160×2700 |

## Layers (common)

Every layer has:

| field | type | default | notes |
|---|---|---|---|
| `id` | string | required | unique within scene |
| `type` | enum | required | `background` \| `imageLogo` \| `kineticText` \| `card` \| `lottie` \| `foregroundFX` \| `chart` \| `codeBlock` \| `particleField` \| `cta` \| `deviceMockup` \| `cursorFlow` \| `bentoGrid` \| `connectorDiagram` \| `metricTicker` \| `comparisonSplit` |
| `at` | number | `0` | layer start (ms) |
| `duration` | number | scene end | layer active window (ms) |
| `z` | int | auto | draw order |
| `entrance` / `emphasis` / `exit` | PresetRef | — | see Motion presets |
| `sfx` | SfxTrigger[] | — | cues relative to `at` |

### The universal spatial / NLE set

Every layer kind — **including `background` and `foregroundFX`** — accepts the
same spatial set. The Studio writes these onto whichever layer the user grabs,
so a kind that does not declare them fails every save with
`Unrecognized key(s) in object: 'position'`.

| field | type | range | notes |
|---|---|---|---|
| `position` | `{ xPct, yPct }` | ±300 | center anchor, percent of canvas. Optional here; `kineticText`, `card`, `imageLogo` and `lottie` re-declare it (required or defaulted). The range allows an off-screen start/end (`xPct: -120` = "fly in from the left"). |
| `scale` | number | 0.05 – 10 | uniform multiplier on the authored size |
| `scaleX` | number | 0.05 – 10 | non-uniform scale on X; overrides `scale` on that axis |
| `scaleY` | number | 0.05 – 10 | non-uniform scale on Y; overrides `scale` on that axis |
| `size` | `{ widthPct?, heightPct? }` | 0 – 400 | LAYOUT size, percent of the canvas (a percent of the *canvas*, not of the parent box) |
| `filters` | object | see below | VISUAL filters on the painted content |
| `keyframes` | Keyframe[] | ≤ 200 | the unified animation surface (see below) |
| `rotation` | number | −3600 – 3600 | degrees around the layer centre |
| `opacity` | number | 0 – 1 | multiplier on the layer's own alpha |
| `visible` | boolean | `true` | `false` hides the layer without deleting it |
| `locked` | boolean | `false` | the layer is not editable in the Studio |
| `trackIndex` | int | 0 – 99 | video track lane (non-overlapping clips share a lane) |
| `trackLane` | int | 0 – 99 | authoring alias for `trackIndex` |
| `blendMode` | enum | `normal` | `normal` \| `multiply` \| `screen` \| `overlay` \| `plus-lighter` |

> **Normalization.** `sanitizeSceneInput()` (published from
> `@motionforge/scene-spec`) strips transient `_`-prefixed properties, heals the
> legacy `_hidden`/`_locked` markers into `visible`/`locked`, and clamps the
> spatial numbers into their legal range. The engine and the Studio both call
> it, so a payload can never be rejected for a transient property. A genuinely
> unknown key is still a validation error.

### The visual filter bag — `filters`

`filters` is a **strict object**; an unknown key is a validation error.

| field | type | range | notes |
|---|---|---|---|
| `blur` | number | 0 – 200 | Gaussian blur radius, px |
| `brightness` | number | 0 – 400 | percent (100 = unchanged) |
| `contrast` | number | 0 – 400 | percent (100 = unchanged) |
| `saturate` | number | 0 – 400 | percent (100 = unchanged) |
| `shadowBlur` | number | 0 – 200 | drop-shadow blur radius, px |
| `shadowColor` | colour | — | drop-shadow colour |
| `cornerRadius` | number | 0 – 400 | corner radius of the layer's own box, px |

> **NAMING.** The visual bag is `filters`, NOT `effects`.
> `foregroundFX.effects` already means something else entirely (an array of
> `vignette` / `filmGrain` / `colorGrade` overlays) and is untouched.

### Track lanes — `trackLanes`

An optional, explicit declaration of the timeline's rows.

| field | type | default | notes |
|---|---|---|---|
| `id` | string | required | unique within the scene |
| `index` | int 0–99 | — | the 0-indexed row the lane occupies. Without it a declared lane's row is implied by its array position, which collides with the lanes the Studio allocates implicitly. |
| `name` | string | — | the display label (`V1`, `A1`, …) |
| `kind` | `video` \| `audio` | `video` | |
| `locked` / `muted` / `collapsed` | boolean | `false` | |

> **Lane rule.** A layer WITHOUT an explicit `trackIndex` gets its OWN row. Two
> clips share a row only when they declare the same `trackIndex` AND their time
> ranges do not overlap.

### The unified keyframes — `keyframes`
A flat list of keyframes; each one is a property, a time and a value.

```jsonc
{ "id": "k1", "timeMs": 1200, "property": "xPct", "value": 40, "easing": "easeInOut" }
```

| field | type | notes |
|---|---|---|
| `id` | string | unique within the layer |
| `timeMs` | number | absolute time on the scene timeline, ms |
| `property` | enum | `xPct` \| `yPct` \| `scale` \| `rotation` \| `opacity` |
| `value` | number | range depends on the property (below) |
| `easing` | enum | `linear` \| `easeIn` \| `easeOut` \| `easeInOut` \| `cubic` — defaults to `easeInOut` |

| property | legal range |
|---|---|
| `xPct`, `yPct` | −300 – 300 |
| `scale` | 0.05 – 10 |
| `rotation` | −3600 – 3600 |
| `opacity` | 0 – 1 |

**Interpolation.** Before the first keyframe the value is the first keyframe's
value; after the last one it is the last keyframe's value; on a keyframe it is
that keyframe's value. Between two keyframes the **left** keyframe's easing is
applied to the normalized progress.

**Precedence.** The flat `keyframes` array wins over the legacy
`tracks` system when both keyframe the same property. The legacy system is
still supported: `tracks: [{ property, keyframes: [{ at, value, ease }] }]`,
where `position.xPct` → `xPct`, `position.yPct` → `yPct`, `scale` → `scale`,
`rotation` → `rotation`, `opacity` → `opacity`, `at` → `timeMs`, and the GSAP
ease name maps onto one of the five easings (`linear`/`none` → `linear`,
`*.in` → `easeIn`, `*.out` → `easeOut`, `*.inOut` → `easeInOut`, anything else
→ `easeInOut`).

**Scale.** `scale` is the uniform base: the effective `scaleX` is
`scaleX ?? scale` and the effective `scaleY` is `scaleY ?? scale`. A `scale`
keyframe drives both axes unless one of them is authored explicitly.


### Motion presets (PresetRef)
`{ name, durationMs?, delayMs?, ease?, staggerMs?, strength? }` — `strength` is a
0.2–2 multiplier on the preset's base intensity. `staggerMs` applies to text layers
(word/char) and multi-element layers.

| category | names |
|---|---|
| **entrance** | `springPop` · `smoothSlideUp` · `maskRevealWipe` · `elasticScale` · `blurFadeIn` · `3dFlipIn` |
| **emphasis** | `pulseGlow` · `floatIdle` · `lightSweep` · `cameraShakeImpact` |
| **exit** | `scaleDownFade` · `whipOutLeft` · `collapseMask` |

Default easing is set per preset (`expo.out`, `back.out(1.7)`, `power4.inOut`, …).
Override `ease` only with a registry name (e.g. `"power3.inOut"`, `"elastic.out(1, 0.75)"`).

### Easing registry
`linear` · `power1–4.in/.out/.inOut` · `expo.in/.out/.inOut` · `circ.in/.out/.inOut` ·
`sine.in/.out/.inOut` · `back.out(1.7|2.5|4)` · `back.in(1.7)` · `back.inOut(1.7)` ·
`elastic.out(1,0.75)` · `elastic.out(1,0.5)` · `elastic.in(1,0.75)` · `bounce.in/.out` ·
`steps(12)` — or `{ "bezier": [x1, y1, x2, y2] }`.

## Layer: `background`
`variant` picks one of:

- **`solid`** — `{ color }`
- **`meshGradient`** — `{ base, blobs[2..6]: { color, xPct, yPct, radiusPct, drift? } }`
  (animated mesh gradient; `drift` 0–2 controls blob wander speed)
- **`particles`** — `{ count 40–600, color?, sizePx?, speed?, direction: up|down|radial|sideways }`
- **`media`** — `{ assetId, blurPx?, dimOpacity?, kenBurns?: { fromScale, toScale, panFrom?: {xPct,yPct}, panTo?: {xPct,yPct} } }`
  (image/video backdrop, optional Ken Burns push)

## Layer: `imageLogo`
`{ assetId, widthPx, heightPx?, position: { xPct, yPct }, mask: rect|circle|squircle|hexagon|blob, cornerRadiusPx?, shadow?, ring?: {widthPx, color, opacity}, glass?: {blurPx, tintColor, tintOpacity}, glow?: {color, strength}, lightSweep?: {at, durationMs, angleDeg?, color?, widthFactor?} }`

`lightSweep` animates a diagonal specular band across the logo at time `at` (ms,
absolute). `mask` applies an SVG clip-path; `glass` wraps the logo in a frosted chip.

## Layer: `kineticText`
`{ text, direction: ltr|rtl (default ltr), role: hero|headline|body|accent|metric, googleFamily?, fontWeight, sizePx, lineHeight?, letterSpacingPx?, align?, position?: {xPct,yPct} (default center), box?: { maxWidthPct, paddingPx, chip?: {color, opacity, radiusPx} }, fill (paint, default #fff), stroke?: {color, widthPx}, shadow?, animateBy: word|char|line (default word), highlight?: {color, radiusPx, paddingPx} }`

- `role` maps to `fonts[]` declarations (font loading is automatic, Google Fonts
  included). Arabic text: set `direction: "rtl"`; numerals inside stay LTR.
- `fill` is a **paint**: a CSS color string or `{ type: "linear", angleDeg, stops: [{color, at 0–100, opacity?}] }`.
- `highlight` renders a marker-style box behind the text that wipes in with the stagger.

## Layer: `card`
All card variants take `position: {xPct, yPct}` (center anchor). `variant` picks one of:

- **`glassCard`** — `{ title?, body?, iconAssetId?, widthPx?, paddingPx?, glass: {blurPx, tintColor, tintOpacity}, radiusPx?, borderOpacity? }`
- **`callout`** — glass card + `{ accentSide: left|right, accentColor }` edge bar
- **`progressBar`** — `{ label?, value 0–100, trackColor?, fill (paint), heightPx?, radiusPx?, showPercentage? }` (animated to `value`)
- **`counter`** — `{ from, to, decimals?, prefix?, suffix?, locale?, role?, sizePx? }` (number tween)

## Layer: `lottie`
`{ assetId, widthPx?, position: { xPct, yPct } }` — Lottie JSON animation, scrubbed by
timeline progress (deterministic; no internal clock).

## Layer: `foregroundFX`
`{ effects: [ … ] }` — full-frame overlays applied above all content:

- **`vignette`** — `{ strength 0–1, color? }`
- **`filmGrain`** — `{ opacity 0–1, sizePx? }`
- **`colorGrade`** — `{ warmth -1…1, contrast -1…1, saturation -1…1, tint?: {color, opacity} }`

## Layer: `chart`
A DATA VISUALISATION layer. `position: {xPct, yPct}` is required.

`{ chartType: bar|line|donut, title?, data[2..12]: { label, value, color? }, accentColor?, showValues?, gridOpacity?, labelColor?, widthPx?, heightPx?, labelSizePx? }`

- `bar` draws one rounded bar per datum, `line` a polyline through the points,
  `donut` a ring split into arcs by the data shares.
- The renderer is pure SVG: crisp at any rasterisation density and fully
  deterministic (no layout measurement, no wall clock).
- `value` is unit-free — the renderer scales to the largest value it is given.

## Layer: `codeBlock`
A SYNTAX-HIGHLIGHTED SOURCE SNIPPET. `position: {xPct, yPct}` is required.

`{ language, code, title?, theme: dark|midnight|matrix, highlightLines?: number[], fontSize?, widthPx?, showChrome?, showLineNumbers? }`

- The highlighter is a dependency-free tokeniser (comments, strings, numbers,
  keywords, punctuation); an unknown language degrades to plain text.
- `highlightLines` are 1-indexed.
- `fontSizePx` is accepted as an alias of `fontSize` and is normalised on save.

## Layer: `particleField`
A FULL-BLEED FIELD OF MOTION PARTICLES. No `position` — it paints the whole canvas.

`{ count 1–400, pattern: float|grid|constellation|sparkle, color, color2?, speed 0.1–4, size, seed, opacity 0–1 }`

- Every particle's position and opacity is a pure function of
  `(timeMs, seed, index)` — the same seed produces the same field on every
  machine, and a headless frame seek is exactly reproducible.
- `sizePx` is accepted as an alias of `size` and is normalised on save.
- Unlike `background.particles`, this is a first-class layer: it carries its own
  timing, motion presets, filters and keyframes, and it can sit mid-stack.

## Layer: `cta`
A CALL-TO-ACTION BUTTON. `position: {xPct, yPct}` is required.

`{ label, sublabel?, variant: primary|glass|outline|pill, accentColor?, bgColor?, textColor?, icon: arrow|sparkles|play|none, widthPx?, heightPx?, radiusPx?, labelSizePx? }`

- The icons are **inline SVG paths** — never an emoji.
- `primary` fills with the accent, `glass` is a translucent panel, `outline` is
  a border, `pill` is fully rounded.

## Camera (2.5D rig)
```jsonc
"camera": {
  "perspective": 1200,                    // px
  "drift": { "amplitudePct": 0.4, "periodMs": 6000, "seed": 7 },  // handheld
  "keyframes": [                          // canonical, tweened in order
    { "at": 0,     "scale": 1,   "xPct": 50, "yPct": 50, "roll": 0, "pitch": 0, "yaw": 0 },
    { "at": 4000,  "scale": 1.6, "xPct": 38, "yPct": 45, "ease": "power3.inOut" }
  ],
  "moves": [                              // sugar, expanded to keyframes by the runtime
    { "move": "slowPushIn", "at": 0, "durationMs": 8000, "strength": 1.2 },
    { "move": "focusTarget", "at": 5000, "durationMs": 1500, "targetLayerId": "logo" },
    { "move": "whipPanLeft", "at": 9000, "durationMs": 600 },
    { "move": "shakeImpact", "at": 9600, "strength": 0.8 }
  ]
}
```
Keyframe fields are optional and inherit from the previous keyframe (`scale` default 1,
`xPct/yPct` default 50 = center, rotations default 0). `pitch`/`yaw` engage the 3D
perspective rig. `moves` compose on top of keyframes.

## Transitions (scene-level)
| kind | fields |
|---|---|
| `wipe` | `{ at, durationMs?, direction: left|right|up|down, featherPx?, color? }` |
| `glitch` | `{ at, durationMs?, intensity 0–1 }` |
| `whipPan` | `{ at, durationMs?, direction: left|right }` (motion-blur slam) |
| `morph` | `{ at, durationMs? }` (blur-dissolve between scene beats) |

## Assets & Fonts
```jsonc
"assets": [ { "id": "logo", "kind": "image", "src": "vault:logo.png" } ],  // https: | data: | vault:
"fonts":  [ { "role": "hero", "family": "Cairo", "provider": "google", "weights": [400, 900] } ]
```
`kind`: `image | video | audio | lottie`. Font `role`s mirror text roles.

## Audio
```jsonc
"audio": {
  "music": { "assetId": "track", "gain": 0.6, "fadeInMs": 500, "fadeOutMs": 1200, "normalize": true },
  "cues":  [ { "at": 250, "sfx": "whoosh", "gain": 1, "pan": 0 } ]
}
```
SFX bank (fixed, 14 cues): `whoosh · pop · click · subImpact · shimmer · riser · typingTick · mouseClick · notificationChime · bassDrop · glitchHit · softSwoosh · counterTick · ambientPad`.
Layers may also declare shorthand cues: `"sfx": [{ "sfx": "pop", "offsetMs": 120 }]`
(relative to the layer's `at`); both are merged into the absolute cue list at render.

## Validation rules (enforced by Zod, strict)
- unique layer ids, unique asset ids, unique font roles
- canvas shape/scale pairs from the table above
- cues within scene duration; keyframes sorted by `at`
- `sfx`/preset/easing names from the registries only

### Structural rules that are NOT obvious from the field list

These are the mistakes an agent actually makes; each is also a line in
`nestedShapeNotes`:
- every layer needs **`id` + `type`**;
- `background.variant` and `card.variant` are **objects** discriminated by their own
  `variant` key (`{"variant":"meshGradient","base":"#05070d","blobs":[…]}`), never a
  bare string;
- motion is `entrance/emphasis/exit: { "name": <preset> }` — there is **no** `preset` key;
- positions are `{"xPct":50,"yPct":45}` objects, never `x`/`y`;
- sizes carry units in the key (`sizePx`, `widthPx`, `blurPx`, `radiusPx`, `paddingPx`);
- gradients are objects (`{"type":"linear","angleDeg":90,"stops":[…]}`), not CSS strings;
- every `assetId` referenced by a layer must be declared in `scene.assets` first.
